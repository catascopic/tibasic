Command Summary
Adds a multiple of one row of a matrix to another.
Command Syntax
*row+(
factor
,
matrix
,
row1
,
row2
)
Menu Location
Press:
MATRX (on a TI-83) or 2nd MATRX (TI-83+ or higher) to access the matrix menu.
RIGHT to access the MATH submenu.
ALPHA F to select *row+(, or use arrows and ENTER.
Calculator Compatibility
TI-83/84/+/SE
Token Size
1 byte
The *row+( adds a multiple of one row to another row and returns the result. It is an elementary row operation used in Gaussian Elimination.
[[1,2][3,4]]
    [[1 2]
     [3 4]]
*row+(10,Ans,1,2)
    [[3  4 ]
     [31 42]]
Advanced Uses
You can add columns instead of rows with the aid of the
T
(
transpose
) command.
Error Conditions
ERR:INVALID DIM
is thrown if one of the row arguments isn't a valid row (larger than the matrix size, or otherwise bad)
